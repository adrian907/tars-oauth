Privacy Policy

Applies to the private, single-user tools Mercator and Alexandria (part of TARS). They are not public services and are used only by their owner.

Data accessed

The applications request only read-only Google API scopes (Gmail, Calendar, Drive, Docs and Sheets, read-only), and only for the owner's own Google account.

Storage and processing

Data obtained from Google APIs is processed and stored exclusively on the owner's private server.

Sharing and use

The data is not shared with third parties, not sold, not used for advertising, and not used to train AI or machine-learning models.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Data deletion

Stored data is deleted at the owner's request.
